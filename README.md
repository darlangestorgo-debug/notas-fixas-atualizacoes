# Notas Fixas — atualizações

Este repositório guarda apenas os instaladores do app **Notas Fixas** (GO! Vendas).
Os apps instalados conferem aqui se há versão nova e se atualizam sozinhos.

Para instalar pela primeira vez, baixe o arquivo `NotasFixas_..._x64-setup.exe` da [versão mais recente](../../releases/latest).
